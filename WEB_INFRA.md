## Landing page
- **Local:** `~/PoolChem-Web/`
- **Repo:** `github.com:amarkviii/PCT-Landing-Page` (private)
- **Host:** Cloudflare **Workers** (Static Assets) — **migrated from Pages ~2026-07-07 by Cloudflare's `workers-autoconfig` bot.** Push to `main` auto-builds via `npx wrangler deploy` (~1–2 min).
- **Deploy REQUIRES `wrangler.jsonc` at repo root** naming the worker `pct-landing-page` (`assets.directory: "."`). Without it every build fails ("A Worker named pct-landing-page already exists"). This bit us 2026-07-07 — builds silently failed for ~11h while pushes still "succeeded" to GitHub.
- **`.gitignore`** excludes `.DS_Store` and `.wrangler/`. **`.assetsignore`** exists but effectiveness unverified — wrangler static assets may not respect it fully.
- **Sep 6, 2026 — git reconnected:** `.git` folder was lost when user moved files. Restored via `git init` + `git remote add origin git@github.com:amarkviii/PCT-Landing-Page.git` + force push. Remote uses **SSH** (not HTTPS). Auto-deploy confirmed working after reconnect.
- **`wrangler login` Safari gotcha:** Safari's HTTPS-Only mode blocks the `http://localhost` OAuth callback with WebKitErrorDomain:303. Fix: open the Cloudflare auth URL in Firefox (handles localhost fine), or use `CLOUDFLARE_API_TOKEN=<token> npx wrangler deploy` to skip browser login entirely. Token created at dash.cloudflare.com/profile/api-tokens → "Edit Cloudflare Workers" template, scoped to poolchemtracker.com zone.
- **Domain:** `poolchemtracker.com` + `www.` (Cloudflare-registered)
- **Email:** Cloudflare Email Routing — `support@poolchemtracker.com` → personal Gmail

## Site conventions / decisions
- **CSS is inline per-page by design** — no shared `styles.css`. Global style changes are done via scripted bulk edit across all ~140 pages (verified safe: e.g. color-var and skip-link changes 2026-07-07). Design is stable; **no redesign planned** — only revisit CSS extraction if a rebrand is undertaken.
- **Accessibility baseline (added 2026-07-07):** every page has a skip link + `<main id="main-content">`; calculator inputs have `for=`/`id` + `inputmode`; `--muted` is `#9fb0c3` (AA contrast). GA (`gtag`) is used and **is disclosed in `privacy-website.html`**.

## Apple campaign tokens (added 2026-06-17)
All landing page App Store links include `ct=` attribution tokens. Tokens by section:
- `web_homepage`, `web_about`, `web_features`, `web_download`
- `blog` (all /blog/ posts), `explained` (all /explained/ pages), `tool` (all /tools/ pages)

Visible in App Store Connect → Acquisition → Campaigns within 24–48h of installs. Attribution is opt-in only (~30–40% of users). When adding new pages, add `?ct=<section>` to any App Store links.

## DNS / email
Receive-only domain. `support@` forwards to Gmail. Nothing sends as the domain.

**DNS state (as of 2026-06-09 — all complete, no further action needed unless transactional email is added):**
- **SPF:** `v=spf1 include:_spf.mx.cloudflare.net -all` (hard fail)
- **DKIM:** `cf2024-1._domainkey` — Cloudflare-managed, auto-rotated
- **DMARC:** `p=reject` with reporting to Cloudflare dashboard + Gmail
- **security.txt:** `/.well-known/security.txt` — **expires 2027-05-25** — bump `Expires` field before that date and redeploy

If transactional email is ever added: add provider's DKIM CNAME + update SPF. DMARC reports go to Cloudflare UI; ignore raw XML in Gmail.

## Link / discovery posture
- Reddit + Bluesky (RSS worker) handle passive link-building — already running; don't suggest "do link building" generically
- AI-bot blocks intentionally OFF in Cloudflare (want AI crawlers indexing blog + llms.txt)
- Cloudflare Crawler Hints (ON — Caching → Configuration) reduces unnecessary crawl requests via 304 headers. IndexNow is NOT a Cloudflare feature. Bing crawls via sitemap and is growing fine (~15–20 clicks/day as of 2026-07-28) — no IndexNow setup needed.
- Google still needs manual GSC indexing requests after significant changes
